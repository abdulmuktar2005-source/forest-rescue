# Forest Rescue asset credits

Polyfork Nature & Forest kit assets used by the game are locally stored in `public/assets/models/`.
The catalog repository is an index only; these GLBs are fetched from each model's official Polyfork CDN URL.

## License choice

Each free model's mesh file (including GLB) is offered under either the Polyfork license or CC BY 4.0. This project uses the **Polyfork license** for game-integrated models: commercial and personal game use, modification, and inclusion in the shipped game are allowed without attribution; the model files may not be redistributed as a standalone asset library. The source `.mjs` modules are not included. See [current Polyfork terms](https://polyfork.dev/licensing) and the repository's [catalog license note](../polyfork-catalog/LICENSE.md).

If these GLBs are ever shared separately or re-hosted as model files, use CC BY 4.0 and retain an individual credit line with each asset, for example: `Forest Ranger by Polyfork (https://polyfork.dev/asset/forest-ranger-6906b0), CC BY 4.0`. Link to each model's own page and record modifications.

## Provenance

- Source collection: [Nature & Forest kit](https://polyfork.dev/kit/nature-forest-kit-f29d6a). The source catalog is maintained separately from this game repository.
- Acquisition date: 2026-11-25.
- Creator: Polyfork / Lucas Martinic.
- Local filenames use the stable Polyfork asset IDs so the attribution and source remain traceable.
- Review actual model bounds, rigs/clips, visual scale, and browser performance during runtime verification; decorative meshes are not used as physics collision proxies.
- The original large terrain GLB remains in the downloaded inventory but is not loaded by the game; its broad uneven underside conflicted with water and the new heightfield. The in-game ground now uses one shared contoured heightfield, while all other listed models are placed as local GLBs.
