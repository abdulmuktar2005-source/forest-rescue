# Fernwood: Forest Rescue

A Three.js forest adventure. Rescue three lost animals, gather food and wood in any order, repair the bridge, and bring your friends back to camp.

## Run locally

```powershell
npm ci
npm run dev
```

## Controls

- WASD or arrow keys: move
- Mouse drag: rotate camera; wheel: zoom
- Space: jump
- Shift: sprint
- E: interact
- Esc: pause

## Deploy

The `Deploy Forest Rescue to GitHub Pages` workflow builds with the `/forest-rescue/` base path and deploys on each push to `main`. Enable GitHub Pages with **GitHub Actions** as the build and deployment source in repository settings. The public model assets and their license notes are in [ASSET_CREDITS.md](ASSET_CREDITS.md).
